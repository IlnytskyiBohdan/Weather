# Weather App

Приложение для просмотра текущей погоды и прогноза на 5 дней по любому городу мира.

## Стек

- Vue 3 (Composition API, `<script setup>`)
- Vite
- Chart.js — график температуры
- Axios
- OpenWeatherMap API

## Возможности

- Поиск города и отображение текущей погоды (температура, влажность, ветер, видимость)
- Переключение между прогнозом на день и на 5 дней
- График изменения температуры
- Избранное (до 5 городов) с быстрым доступом на отдельной вкладке
- Автоопределение города пользователя по IP при первой загрузке
- Светлая и тёмная тема
- Локализация: английский / украинский
- Адаптивная вёрстка (от 320px)
